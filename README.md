# PG Manager

A web-based **PG Fee & Room Management System** built using Python, Flask, SQLite, HTML and CSS.

## Features
- Dashboard with tenant, room and bed statistics.
- Add, edit and manage tenant records.
- Floor, room and bed management.
- Track occupied and vacant beds.
- Automatic monthly rent generation and payment reminders.
- Manage joining advances and rent payments.
- Maintain previous tenant and payment history.

## Tech Stack
- Python
- Flask
- SQLite
- Flask-SQLAlchemy
- HTML & CSS

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/RashmiSharma-1409/PG-Manager.git
   ```

2. Navigate to the project:
   ```bash
   cd PG-Manager
   ```

3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000/` in your browser.
